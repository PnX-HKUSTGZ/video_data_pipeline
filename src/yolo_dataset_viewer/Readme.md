# 通用 YOLO 数据集网页浏览器

独立的 `src/yolo_dataset_viewer` 模块可浏览任意来源的标准 YOLO **检测、分割、OBB、姿态**数据集，并对**检测和姿态**进行差分编辑。输入只需图片、标签及可选的数据集 YAML，不需要本仓库的 `run.json`、`frames.jsonl`、模型或其他生成记录，也不会导入流水线、Torch 或 Ultralytics。分割和 OBB 当前仅支持浏览。

## 启动

以下命令均在仓库根目录执行。

```bash
uv run --locked --extra viewer yolo-viewer --host 127.0.0.1 --port 8765
```

打开 <http://127.0.0.1:8765>，填写**服务所在机器**的数据集目录或 `.yaml` / `.yml` 文件路径，选择标注任务后打开。目录里有多个 YAML 时，网页会列出候选供选择。服务器上运行时，可以从自己的电脑建立 SSH 转发：

```bash
ssh -N -L 8765:127.0.0.1:8765 <user>@<server>
```

然后在电脑浏览器访问同一个本地地址。服务默认仅监听回环地址，面向单用户；没有账号或多用户会话管理。每次打开都会替换当前数据集，取消旧索引并释放旧缓存。

## 标准格式与路径

- YAML 支持 `path`、`train`、`val`、`test`（另接受 `valid`、`validation`、`minival`）、`names` 列表或连续整数映射、`nc`、姿态任务的 `kpt_shape`。划分来源支持目录、图片清单 TXT、多来源列表；无需同时具有训练集和验证集。
- 没有 YAML 时，识别 `images/train ↔ labels/train`、`train/images ↔ train/labels`、`images ↔ labels`、按划分排列的图片/标签同目录，以及无划分的同目录图片/标签。保持嵌套路径，按图片同名 `.txt` 配对；无类别名称时显示 `class_<id>`。
- YAML 相对 `path` 以 YAML 所在目录为基准；没有 `path` 则使用 YAML 所在目录。划分来源相对数据集根目录。网页「路径设置 → 根目录覆盖」可重新指定根目录；配置中的绝对来源仍原样使用。
- TXT 内绝对图片路径原样使用，`./`、`../` 路径相对 TXT 文件；其他相对路径分别检查 TXT 目录和数据集根目录，存在两个不同文件时提示歧义。全部路径规则独立于训练启动目录和 Ultralytics 全局设置。
- 读取本地已解压数据，不下载文件或执行 YAML 的 `download` 内容。常见 JPG/PNG/BMP/TIFF/WebP 等由 Pillow 解码；具体编解码器不支持的格式、损坏文件会在查看时提示，不中止其余样本的索引。

| 任务 | 每行标准标签 | 显示方式 |
| --- | --- | --- |
| 检测 | `class cx cy w h` | 矩形框与类别 |
| 分割 | `class x1 y1 … xn yn`，至少 3 个点 | 多边形轮廓与填充 |
| OBB | `class x1 y1 … x4 y4` | 四点旋转框 |
| 姿态 | `class cx cy w h` + N 组 `(x,y)` 或 `(x,y,v)` | 框、关键点与编号 |

所有坐标为相对图片宽高的归一化坐标。OBB 与四点分割的列数相同，必须选择正确任务，浏览器不猜测。姿态优先使用网页中填写的数量/维度，否则读取 `kpt_shape: [N, 2或3]`；缺少则提示补充。可见性 `0` 不显示，`1` 用空心点，`2` 用实心点；二维标签的负坐标按缺失关键点处理。关键点编号从 0 开始，不推测骨架连接。

## 浏览、统计与资源

- 按划分、类别、标签状态和文件名/相对路径筛选；每页 48 张缩略图。点击图片进入单图视图，可滚轮缩放、拖动、适应窗口，使用按钮或左右方向键翻页。编辑导致当前图片移出筛选结果时，详情会提示这一状态，上一张/下一张会进入剩余结果中紧邻的图片。
- 可以切换标注与文字，点击目标轮廓内或侧栏目标，查看原始标签行和归一化坐标。原图和缩略图都应用 EXIF 方向，标注以方向校正后的图片为坐标系。
- 类别筛选选择「包含该类别」的图片；统计和单图仍包含这些图片的全部有效目标。类别统计分别显示实例数与包含该类的图片数。跨划分重复图片按各划分条目计数，另显示唯一图片数；同一划分内的重复来源会去重。
- 空标签与缺失标签分别记录，均可浏览。非法类别、数值/坐标或列数错误定位至文件与行；同一文件的有效行继续渲染并计数。异常原行不会被静默丢弃或裁剪；编辑时可以显式删除或修复，未处理的异常阻止导出。标准标签没有置信度，因此没有置信度统计。
- 后台索引仅扫描路径和标签，不解码图片、不保留全部目标几何；缩略图进入视口附近 320 px 后才请求，编辑刷新保留未变化的图片节点。服务器最多同时解码 2 张图片，原图与缩略图共用 32 MiB 编码缓存，同图并发请求合并解码；图片接口仅接受当前索引登记的样本编号。
- 切图并行读取图片和最新标注，停止切换 180 ms 后依次预加载前后各一张图片；省流量或 2G 网络关闭预加载。浏览器缓存最多 4 张图片、96 MiB（按像素与传输数据估算），切换数据集或重新扫描时释放。图片缓存按会话、样本及文件版本区分，标注仍按当前草稿修订读取。
- 连续筛选和切图取消过期请求，后台预加载不会覆盖当前视图；缩放和拖动在同一动画帧内合并绘制。列表、统计与草稿通过 `GET /api/datasets/{id}/view` 一次获取一致快照；浏览状态的源文件冲突检查最多缓存 1 秒，保存和导出仍执行完整校验。
- 无草稿时源数据变化后可「重新扫描」。有草稿时，源 YAML、清单、标签的指纹或图片状态变化会显示冲突，暂停编辑与导出；保留草稿等待源文件恢复，或选择「放弃草稿」重新建立基线。重新扫描不会偷偷把旧草稿应用到已变化的源数据。
- 单纯浏览不向数据集写文件。编辑仅创建下述草稿数据库，不创建磁盘缩略图；日志默认放在 `${XDG_CACHE_HOME:-~/.cache}/yolo-dataset-viewer/viewer.log`，5 MiB 轮转、保留 3 份；可通过 `--log-file` 修改。退出时取消索引/导出任务并释放工作线程、内存索引和缩略图缓存。
- 桌面端集中展示图片条目与统计；窄屏设备的单图视图把画布固定在上方，坐标和关键点属性可独立滚动。API 类型文档见服务的 `/docs`：打开数据集 `POST /api/datasets`；查询索引状态、分页样本、当前筛选位置、统计、单图详情和图片均使用返回的数据集 ID。

## 差分编辑与自动保存

打开检测或 pose 数据集后，顶部提供「类别与关键点」「撤销」「重做」「放弃草稿」「导出 / 应用」。每次完成操作会自动保存到根目录的 **`.yolo-viewer-draft.sqlite3`**；SQLite 写事务期间可能短暂产生辅助文件，提交后清理。**导出前不会改动原图片、标签或 YAML。** 同一文件区分不同配置的草稿，保存操作历史；刷新网页、切换数据集或重启服务后重新打开，可恢复已保存修改并继续撤销/重做。无需手动保存。

- 「保存中」表示等待服务端提交；只有提交成功才显示「已保存到草稿」。失败保留本页待保存操作，可以重试；完成保存前不允许翻图、关闭单图或切换数据集。若另一标签页更新了草稿，版本冲突会阻止覆盖，可「读取最新草稿」后继续。浏览器强制关闭前仍显示未保存的操作不保证恢复。
- 类别可以新增、重命名或删除。删除类别会移除该类所有目标，保留图片；确认前显示影响范围。类别内部使用稳定标识，导出时才压缩为连续的 YOLO 类别编号。类别面板中尚未确认的名称或关键点输入会保留，分别点击对应按钮后才写入草稿。
- 每个类别维护独立的关键点列表：新增、重命名、上下移动或删除。重命名、排序保留对应坐标；新增点未标注；删除点移除该类别全部目标上的对应坐标，操作可撤销。缺少点名时显示 `keypoint_0` 等占位名称，不推断语义。
- 单图工具包括「浏览」「选择 / 改框」「新增目标」「关键点」。滚轮缩放；空格或中键拖动平移。选中目标后可以拖动框、拖动八个边界控制点、修改类别、输入框坐标或删除目标；调整框不会移动关键点。
- 选中关键点后在图像上点击放置或拖动，侧栏可输入坐标并设置未标注、遮挡、可见。把点改为未标注只清除当前目标的这个点，不删除类别定义。换目标类别时按点名迁移，同名点保留，其余新点留空。
- 删除图片会标记删除其全部划分引用；可在「已删除」筛选中恢复，也可以撤销。损坏图片虽不能编辑坐标，仍可在详情中标记删除。列表、筛选、统计和详情都显示草稿合并后的结果。
- 异常标签行保留原始文本和定位信息；可显式删除或用一个正确目标替换，均保存为可撤销差分。未解决的异常不会混入导出结果。

任一类别包含关键点时，导出使用 pose，`kpt_shape: [最大类别点数, 3]`；每类按自身列表顺序排列，不适用槽位和未标注点补 `0 0 0`。二维来源的有效点转为可见。每类有效点名写入 YAML 的 `kpt_names` 映射；此描述字段不改变标准 YOLO 标签格式，本浏览器重新打开时可恢复各类别实际列表，无需草稿。全部类别列表为空时导出为检测。关键点位置结构变化时移除失效的 `flip_idx` 等位置相关配置，并在预检中说明。

## 导出与恢复

「导出 / 应用」先预检并展示类别编号、任务/关键点格式、文件操作清单、异常、预计空间和删除数量。预检会解码保留的图片以检查损坏，因此大数据集可能需要等待。至少保留一个类别，异常标签与损坏图片需先处理或标记删除。导出使用一个固定草稿版本，期间暂停编辑与数据集切换。

**导出新数据集**：填写源数据集以外的输出目录，不覆盖非空目录。输出包含原始字节复制的图片、重写的标准标签、划分 TXT 与 YAML；图片和标签路径保持配对，处理嵌套同名及外部来源，使用相对路径，可以独立迁移。没有划分的数据归到 `train`。写入临时目录并校验完成后发布；原目录和草稿保留，可以继续编辑或再次导出。

**应用回原数据集**：预检限制图片、标签、配置及划分来源都位于数据集根目录内，符号链接按实际目标判断。引用外部文件的数据可正常编辑和暂存，但只能导出新数据集。确认清单后，先备份即将覆盖或删除的文件与草稿，再更新登记的标签、图片和所选 YAML；使用 `.yolo-viewer-splits/` 下的新清单避免直接改写共享的原 TXT。其他 YAML 不会同步更新。成功后重新索引并清空当前工作区草稿，其他配置草稿保留。

原地导出的备份位于数据集相邻的 `.<数据集名>.viewer-backup-*` 目录，网页显示实际位置。备份不会自动删除。发生写入失败时尝试恢复；进程中断后再次打开会列出未完成应用的备份，恢复后才能继续编辑。即使中断期间任务格式改变而无法正常索引，也可以进入恢复流程。恢复前检查备份和当前文件，发现后续外部改动时停止，避免覆盖未知内容。恢复范围限定于这次导出记录的文件及当前草稿工作区。

编辑 API 在 `/api/datasets/{id}` 下提供 `GET /draft`、`POST /draft/operations`、`POST /draft/undo|redo|discard`；写请求携带 `expected_revision`。导出使用 `POST /exports/preview`、`POST /exports` 和 `GET /exports/{export_id}`；恢复使用 `GET /exports/recoveries` 与 `POST /exports/recover`。所有写接口检查同源，具体操作类型和字段见 `/docs`。

## 验证

```bash
uv run --locked --extra viewer pytest -q tests/test_viewer.py tests/test_viewer_edits.py tests/test_viewer_exports.py tests/test_viewer_edit_api.py
uv run --locked --extra viewer mypy src/yolo_dataset_viewer

# 真实 Chromium 交互测试；首次需要安装测试浏览器
uv run --locked --extra viewer --group browser playwright install chromium
CUDA_VISIBLE_DEVICES='' uv run --locked --extra viewer --group browser pytest -q tests/test_viewer*.py
```

测试使用只含标准文件的外部风格数据，覆盖四种任务、目录和 TXT 解析、异常诊断、八种 EXIF 方向、浏览只读性、索引取消及万级样本索引/差分编辑；另验证关键点迁移、跨重启历史、版本冲突、导出与中断恢复。真实 Chromium 测试通过页面操作验证保存、绘框、关键点、类别管理、筛选及两种导出后重新打开。未安装 Playwright 或 Chromium 时浏览器测试跳过。截图保存在项目 `.cache/viewer-checks/`，测试服务与临时数据在结束时清理。
