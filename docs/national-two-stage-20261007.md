# 全国赛红蓝双方：两阶段数据生成（2026-10-07）

`datasets/rm26_fps_videos/videos/全国赛` 中的全部 259 个视频已处理完成：红方 129 个、
蓝方 130 个，总时长 141,301 秒（39.25 小时），输入文件共 30,349,430,810 字节。
输出为 `datasets/generated/rm26_two_stage/national_20261007/`，约 31.82 GiB。

## 复现命令与配置

```bash
uv run --locked video-dataset run \
  --config configs/rm26_national_two_stage.yaml --devices 5 6
```

重跑时用 `--output` 指定新的空目录。使用当前环境中空闲的两张 RTX 4090（GPU5、6），
每卡一个常驻工作进程，长视频优先。设备、PID 和运行快照保存在输出目录中。

- `pipeline: two_stage`：本地 YOLO26s 检测器 + 按类别映射的 marker/station LiteHRNet-30。
- 递归包含全国赛红方、蓝方目录；固定输入清单保存于 `run.json`。
- 2 FPS，检测 batch 8，imgsz 640，检测阈值 0.5，IoU 0.7。
- 两个 LiteHRNet 的热图阈值均为 0.1、ROI batch 1、crop_margin 0；不启用在框概率筛选。
- 保留原生模型预处理及 FP32 推理；每目标统一输出 12 个槽位，非适用槽位补零。
- 每视频筛选有效帧后按时间顺序 80/20 划分，分界两侧各排除 5 秒。
- `save_video: false`，只生成数据集及抽检预览，未保存逐帧推理视频。
