## 运行命令与参数

```bash
uv run --locked video-dataset run \
  --config configs/rm26_national_red_pose.yaml --devices 0 2 3 7
```

重跑时添加 `--output` 指定新的空目录。单卡配置仍使用普通的 `device: 0`，
多卡命令覆盖该值，实际设备和工作进程记录在 `parallel.json`。
本轮选择全部四张空闲 RTX 4090，其余 GPU 已有任务。

- YOLO11s-pose：`yolopose/v11.02/best.pt` 及其 `openvino_best/metadata.yaml`。
- 类别：`0: pillar`、`1: exchange`；12 个关键点，训练标签每行 41 列。
- 2 FPS 按时间戳采样，batch 8，imgsz 640，目标与关键点阈值均为 0.5，IoU 0.7。
- 保持原有推理精度设置；JPEG 质量 95，`save_video: false`。
- 每视频先筛选，再按时间顺序分配前 80%/后 20%，分界两侧各排除 5 秒。
- 每卡一个常驻模型进程，动态领取完整视频，长视频优先；按固定输入顺序合并。

没有添加哈希、文件锁或恢复功能。各工作进程独立写产物，只有主进程写总清单。
